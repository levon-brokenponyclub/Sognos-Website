# Approve — Full Instructions

## Purpose
The user eyeballs the scaffolded page in Dia and confirms it looks structurally
correct before Pass begins.

## What Claude does during Approve
- Nothing automatically — Approve is user-driven
- If the user comes back with corrections, apply them and re-notify
- Only mark Approve complete when the user explicitly confirms

## What to watch for (guide for the user)
- Does the overall layout/proportion match the Routable reference?
- Are sections in the right order?
- Is spacing roughly right at desktop and mobile?
- Are any components obviously missing or broken?

## When Approve is done
Update the status table in `docs/ROLLOUT_PROCESS.md` and notify the user.
